# Changelog

This repository publishes two npm packages, each with its own changelog. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the packages adhere to
[Semantic Versioning](https://semver.org/).

- [`@qed-proof/sdk`](packages/sdk/CHANGELOG.md)
- [`@qed-proof/cli`](packages/cli/CHANGELOG.md)

Both packages are released together from one tag, `sdk-js-vX.Y.Z`, so a tag always names the same version of each.
